# Non-functional tests – web UI (UC-01 to UC-06, UC-09 to UC-12)

**Author:** Emir Gül · **Date of the results:** 21.11.2026 (browser checks from 17.11 to 20.11) · **Code:** `main` with PR #31 and PR #22 · Part of the Software Testing Report, see the [web UI section](../../testing/web_ui_test_section.md).

The non-functional requirements are in the [Requirements Specification](../../requirements_specification.md) (NFR-01 to NFR-07). This file lists what was checked on the web pages. The facility page is in the [facilities file](facilities.md); password hashing and log in security are in the [accounts and profiles file](accounts-profiles.md).

**Browser checks** were made with Playwright 1.65 against the demo (`scripts/run_demo.py`, demo accounts and invented events) in **Firefox** (Gecko) and **WebKit** (the engine of Safari), each at **1280 px** (desktop) and **360 px** (phone). Every run recorded page errors in the console and measured horizontal scrolling (`document.documentElement.scrollWidth` against the window width).
