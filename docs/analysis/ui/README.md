# UI Mockups (preliminary)

Low-fidelity mockups of the main CampusEvent screens. Each screen is an HTML page (open it in a browser) with a PNG picture. Yellow notes show error cases and rules from the use cases. The screens are described in [`ui_spec_lite.md`](ui_spec_lite.md), written in the UI Spec Lite format of the course guide, which can be given to an AI mockup tool (for example Figma AI) to produce higher-fidelity designs. The final design will be refined with the team.
